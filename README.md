# 头痛日记

一个给偏头痛患者用的记录 App（网页 App / PWA）。在 iPhone 上「添加到主屏幕」后，会像普通 App 一样全屏打开、断网也能用。**所有数据只保存在手机本地（IndexedDB），不会上传到任何服务器。**

## 功能

- **首页**：今日状态（无痛 / 轻 / 中 / 重）、六项打卡（经期、饮食、睡眠、压力、运动、服药）、近 30 天趋势图，右下角「+」快速记录发作
- **记录发作**：开始时间、程度、部位、伴随症状、持续时间、可能诱因（支持自定义）、服药及效果、备注
- **记录**：按月份列出全部发作，点开可修改或删除
- **分析**
  - 月度统计、发作日历（颜色深浅 = 程度，下方紫红短线 = 经期，蓝点 = 服药），点日期可查看、补记
  - 你标记的诱因占比
  - 智能分析（记录满 21 天且至少 4 次发作后开启）：
    - 各因素与发作的关系：贝叶斯逻辑回归，给出校正后的风险倍数、95% 可信区间和可信度
    - 今日发作风险：交叉验证 AUC ≥ 0.6 时才显示
    - Spearman 相关性、睡眠时长分组发作率
    - 近 6 个月趋势（泊松回归）
    - 经期前后发作占比、预计下次经期
    - 发作时段、药物效果、每月止痛药天数提醒
- **我的**：称呼、常用药物（区分止痛 / 预防）、就诊摘要（可复制或分享给医生）、导出 CSV、导出 / 导入备份、清除数据

## 安装到 iPhone

App 需要放在一个 https 网址上，朋友用 Safari 打开后添加到主屏幕。以下任选一种（都免费）：

### 方式 A：Netlify Drop（最简单）

1. 电脑浏览器打开 <https://app.netlify.com/drop>，注册 / 登录
2. 把整个 `migraine-diary` 文件夹拖进页面
3. 得到一个类似 `https://xxx.netlify.app` 的网址

### 方式 B：GitHub Pages

1. 新建一个 GitHub 仓库，把 `migraine-diary` 文件夹里的所有文件上传到仓库根目录
2. 仓库 Settings → Pages → Branch 选 `main`，保存
3. 一两分钟后得到 `https://你的用户名.github.io/仓库名/`

### 在朋友的 iPhone 上

1. 用 **Safari** 打开上面的网址（必须是 Safari）
2. 点底部「分享」按钮 → 「添加到主屏幕」 → 「添加」
3. 以后从桌面的「头痛日记」图标打开

## 数据安全提示

- 数据存在「主屏幕上的这个 App」里。**删除主屏幕图标会同时删除数据**，删除前请先在「我的 → 导出备份」
- 建议每月导出一次备份（存到「文件」App 或发给自己）。换手机时，在新手机上「导入备份」即可
- 更新 App：只需替换网站上的文件，朋友下次打开会自动拿到新版本，数据不受影响

## 本地预览

```bash
python3 -m http.server 8765 --directory migraine-diary
```

然后打开 <http://localhost:8765>。

## 文件结构

```
index.html            页面入口
manifest.webmanifest  PWA 配置（名称、图标）
sw.js                 离线缓存
css/app.css           样式（含深色模式）
js/app.js             界面与交互
js/stats.js           分析算法
js/db.js              本地存储（IndexedDB）
js/util.js            日期工具、图标、选项
icons/                App 图标
```
